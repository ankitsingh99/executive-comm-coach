## Reporting a Vulnerability

We take the security and privacy of this on-device executive communication coach very seriously.

If you discover a security vulnerability or privacy leak (such as unredacted PII egress or biometric storage flaws):

1. **Do not create a public GitHub Issue.**
2. Report the vulnerability privately by emailing the maintainer or opening a private security advisory through the [GitHub Security Advisory Dashboard](https://github.com/ankitsingh99/executive-comm-coach/security/advisories/new).
3. Include:
   - Steps to reproduce the issue
   - Affected components (e.g. `core.privacy`, `core.asr_diarization`)
   - Proof of concept payload or script
4. You will receive an initial response within 48 hours, followed by a remediation timeline.
